# 블레이즈 막대 우클릭 번개 기능

블레이즈 막대(Blaze Rod)를 들고 우클릭하면 플레이어가 바라보는 지점에 번개가 생성됩니다. 구현 코드는 [`MyFirstMod.java`](src/main/java/com/example/myfirstmod/MyFirstMod.java)에 있습니다.

## 수정한 핵심 부분

### 1. 우클릭 이벤트 등록

`onInitialize()`에서 Fabric의 `UseItemCallback.EVENT`에 콜백을 등록했습니다. 아이템 사용 시 플레이어, 월드, 손 정보를 받아 기능 실행 여부를 판단합니다.

### 2. 블레이즈 막대와 서버 실행 여부 확인

들고 있는 아이템이 비어 있거나 블레이즈 막대가 아니면 `PASS`를 반환해 기본 동작으로 넘깁니다. 클라이언트 월드에서도 처리하지 않습니다. 따라서 번개 생성은 서버에서 한 번만 처리됩니다.

### 3. 플레이어의 조준 지점 계산

`player.pick(128.0D, 1.0F, false)`로 시선 방향을 따라 최대 128블록 범위의 충돌 지점을 구하고, `HitResult`의 위치를 번개가 생성될 좌표로 사용합니다.

### 4. 번개 엔티티 생성 및 월드에 추가

`lightning_bolt` 엔티티 타입을 가져와 `LightningBolt`를 만들고, 조준 지점에 배치한 뒤 `serverLevel.addFreshEntity(lightning)`로 월드에 추가합니다. 성공적으로 처리한 경우 `SUCCESS_SERVER`를 반환합니다.

## 실행 흐름

`블레이즈 막대 우클릭` → `블레이즈 막대인지 확인` → `서버에서 처리` → `조준 지점 계산(최대 128블록)` → `해당 위치에 번개 생성`

## 참고 사항

조준 대상이 없는 경우에도 `pick` 결과의 위치를 사용하므로, 최대 사거리 끝 지점에 번개가 생성될 수 있습니다. 번개 생성에 아이템 소모 처리는 추가되어 있지 않습니다.
